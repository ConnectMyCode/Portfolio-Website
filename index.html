Projects

AI Support Ticket Triage System

Spring Boot, React.js, JWT, BCrypt, PostgreSQL, Docker, AWS EC2, RDS, Postman, JUnit 5

  • Built a Spring Boot REST API with 12 endpoints, 5+ request/response structures, 2 enumerations, 8 service classes and 4 status transitions (OPEN → TRIAGED → RESPONDED → CLOSED), plus pagination and status/priority filtering.
  • Secured 9 of 12 endpoints with JWT and Spring Security, with BCrypt password hashing, user-specific ticket access and a separate admin API.
  • Added AI triage that generates 6 outputs per ticket (category, priority, tags, sentiment, summary, suggested response), with 2 APIs to save results and submit final resolutions.
  • Deployed with Docker on AWS EC2 with a private Amazon RDS PostgreSQL database, reachable only from the backend through EC2 security groups. The React/Nginx frontend container is the next step toward a 3-tier setup.
  • Tested all 12 endpoints with Postman and wrote 6 JUnit 5 tests using MockMvc and Mockito.
